# Pharos NFT Creator — دليل المستخدم

## نظرة عامة

مهارة Pharos Agent Center تُمكّن وكلاء الذكاء الاصطناعي من بناء مجموعات NFT كاملة الدورة على سلسلة Pharos. تدعم أوضاع التوليد (المبني على السمات)، والصور الفردية، والصورة الواحدة. تتفاعل مع الوكيل بلغة طبيعية، ويتولى هو إنشاء الصور، ورفعها إلى IPFS، ونشر العقود الذكية، وسكّ العملات، وتوزيعها.

## الميزات

- فحص تلقائي للتبعيات عند كل استدعاء (Python، Forge، Cast، Node.js، إلخ)
- إنشاء تلقائي لملف `.env` بمتغيرات البيئة
- تطبيع تلقائي للمفتاح الخاص (ألصقه مع بادئة `0x` أو بدونها)
- ثلاثة أوضاع للصور الفنية: توليدي (سمات)، صور فردية، صورة واحدة
- إنشاء NFTs توليدية بطبقات السمات وأوزان الندرة
- تركيب الصور خارج السلسلة من طبقات PNG باستخدام Python Pillow
- رفع الصور ومجلد البيانات الوصفية إلى IPFS عبر Pinata (SDK للملفات، REST API للمجلدات)
- نمط BaseURI — العقد يُرجع `ipfs://CID/tokenId` لكل NFT
- بيانات شبكة Pharos مدمجة — اختر testnet/mainnet، وRPC يُهيَّأ تلقائيًا
- نشر عقد ذكي ERC-721 مع 6 أوضاع سك (عام مجاني/مدفوع، المالك فقط، القائمة البيضاء مجاني/مدفوع، القائمة البيضاء مجاني + عام مدفوع)
- صفحة هبوط اختيارية للسك (HTML + ethers.js، تهيأة تلقائية)
- سكّ مجمّع وإرسال جوي إلى أي عدد من المحافظ (مباشرة أو من ملف)
- دعم القائمة البيضاء عبر شجرة Merkle (تُولَّد تلقائيًا مع الإثباتات الصحيحة)
- تحليلات حاملي العملات مع تصدير JSON/CSV
- يتواصل الوكيل بلغة المستخدم

## التشغيل الأول — الفحوصات التلقائية

عند استدعاء المهارة لأول مرة، يُنفذ الوكيل تلقائيًا **المرحلة 0: فحص التبعيات**:

1. **يفحص الأدوات** — Python، Pillow، Forge، Cast، jq، Node.js، Pinata SDK. ويعرض تثبيت أي أداة مفقودة.
2. **ينشئ ملف `.env`** — إذا لم يكن موجودًا في المشروع، ينسخ من `.env.example` مع القيم الفارغة.
3. **يتحقق من المتغيرات** — يفحص ما إذا تم تعبئة `PRIVATE_KEY` و `PINATA_JWT`.
4. **يرشدك إلى `.env`** — إذا كانت الحقول فارغة، يعرض **مسار الملف** ويخبرك بالأسطر التي يجب تعبئتها.

عناوين RPC لشبكة Pharos وبيانات الشبكة **مدمجة في المهارة** — لا حاجة لأي تهيئة يدوية. ما عليك سوى اختيار الشبكة أثناء الإعداد.

مثال على المخرجات:
```

Required:
  [OK]   Python 3.10+         — Python 3.12.4
  [OK]   Pillow library       — ok
  [OK]   Foundry Forge        — forge 0.2.0

  [OK]   jq                   — jq-1.7
  [OK]   Node.js              — v20.20.0
  [OK]   Pinata SDK           — ok

  [MISS] PRIVATE_KEY          — not set (needed for: deployment, minting)

Network: will be selected at configuration (Pharos Testnet / Pharos Mainnet)

Result: 7/7 required OK. 0/2 optional set.
Action: Can proceed with configuration. Deployment and IPFS will require env vars.
```

## متغيرات البيئة

تُخزَّن جميع البيانات السرية في ملف `.env` في جذر المشروع. **لا تلصق المفاتيح مباشرة في المحادثة.**

ملف `.env` (يُنشأ تلقائيًا):
```bash
# مفتاح محفظتك الخاص.
# ألصقه مع بادئة 0x أو بدونها — المهارة تطبعه تلقائيًا.
# الأمان: عبّئ الملف مباشرة. لا تلصقه في المحادثة.
PRIVATE_KEY=

# رمز Pinata JWT — كيفية الحصول عليه:
#   1. اذهب إلى https://app.pinata.cloud → سجّل / سجّل الدخول
#   2. الشريط الجانبي الأيسر → "API Keys" → "New Key"
#   3. سمّه (مثلاً "nft-builder")، اترك الصلاحيات الافتراضية
#   4. اضغط "Create Key" → انسخ الـ JWT (نص طويل يبدأ بـ "eyJ...")
#   5. ألصقه أدناه
PINATA_JWT=

# الشبكة تُختار أثناء التهيئة — لا حاجة لتعيين عنوان RPC يدويًا.
```

### من أين تحصل على القيم

| المتغير | المصدر |
|----------|--------|
| `PRIVATE_KEY` | MetaMask → النقاط الثلاث → تفاصيل الحساب → عرض المفتاح الخاص. ألصقه مع `0x` أو بدونها — يُطبَّع تلقائيًا |
| `PINATA_JWT` | [app.pinata.cloud](https://app.pinata.cloud) → API Keys → New Key → انسخ الـ JWT |

## تحضير الصور الفنية

تدعم المهارة **ثلاثة أوضاع للصور الفنية**:

### الوضع أ: توليدي (سمات)

النهج التوليدي الكلاسيكي — تُدمج طبقات سمات متعددة عشوائيًا. يجب أن تكون جميع الملفات بصيغة PNG، بتنسيق RGBA، وبنفس الأبعاد.

```
traits/
├── Background/
│   ├── blue.png
│   ├── red.png
│   └── green.png
├── Body/
│   ├── normal.png
│   └── muscular.png
├── Headwear/
│   ├── none.png          (ملف PNG شفاف فارغ)
│   ├── crown.png
│   ├── cap.png
│   └── helmet.png
└── Weapon/
    ├── none.png
    ├── sword.png
    └── axe.png
```

### الوضع ب: صور فردية

مجلد من ملفات PNG الجاهزة — كل ملف = NFT فريد. تُعيّن وزن ندرة لكل صورة. وفّر تهيئة JSON/CSV أو أدخلها يدويًا.

```
my-nfts/
├── 001_samurai.png     (weight: 10 — أسطوري)
├── 002_ninja.png       (weight: 30 — غير شائع)
├── 003_wizard.png      (weight: 5 — أسطوري)
├── 004_knight.png      (weight: 55 — شائع)
└── ...
```

تهيئة (اختيارية، JSON):
```json
[
  {"file": "001_samurai.png", "weight": 10, "name": "Samurai"},
  {"file": "002_ninja.png", "weight": 30, "name": "Ninja"}
]
```

### الوضع ج: صورة واحدة

ملف PNG واحد لجميع الـ NFTs. كل رمز يبدو متطابقًا. مناسب لبطاقات العضوية والتذاكر وNFTs الخدمية.

```
collection-art.png    (صورة واحدة للمجموعة بأكملها)
```

### أوزان الندرة (للوضعين أ و ب)

تحدد الأوزان مدى تكرار ظهور كل تنوع من السمات. وزن أعلى = أكثر شيوعًا:

| الفئة | الوزن | التكرار |
|----------|--------|-----------|
| أسطوري | 1–4 | نادر جدًا |
| نادر | 5–19 | غير شائع |
| غير شائع | 20–49 | متوسط |
| شائع | 50–100 | متكرر |

مثال: إذا كانت Headwear تحتوي على Crown(5)، Cap(30)، Helmet(40)، None(25)، ستظهر Crown في حوالي 5% من الـ NFTs المُنشأة.

## الاستخدام

### 1. بدء إنشاء المجموعة

أخبر الوكيل:
> "Deploy a generative NFT collection on Pharos"

سيتحقق الوكيل من التبعيات، وينشئ `.env` إذا لزم الأمر، ويبدأ التهيئة التفاعلية.

### 2. أجب على أسئلة التهيئة

سيسأل الوكيل عن:
- **أي شبكة تريد استخدامها** — Pharos Atlantic Testnet (مجاني، للاختبار) أو Pharos Mainnet (رموز PROS حقيقية)
- اسم المجموعة والرمز
- الوصف
- العرض الإجمالي (الحد الأقصى لعدد الـ NFTs)
- نوع السك (انظر أدناه)
- **وضع الصور الفنية** — توليدي (سمات)، صور فردية، أو صورة واحدة
- تفاصيل الصور الفنية: طبقات السمات، أو مجلد PNGs + أوزان، أو مسار ملف PNG واحد

### 3. أنواع السك

سيرشدك الوكيل لكل خيار ويساعدك في الاختيار. ستة أنواع متاحة:

| النوع | الوصف | حالة الاستخدام |
|------|-------------|----------|
| **عام مجاني** | أي شخص يمكنه السك مجانًا | مجموعات المجتمع المفتوحة |
| **عام مدفوع** | أي شخص يدفع سعرًا محددًا | المجموعات المتميزة |
| **المالك فقط** | فقط مالك العقد يمكنه السك | الإرسال الجوي، التوزيعات الخاصة |
| **قائمة بيضاء مجانية** | فقط العناوين في القائمة البيضاء يمكنها السك مجانًا | إصدارات المجتمع الحصرية |
| **قائمة بيضاء مدفوعة** | فقط العناوين في القائمة البيضاء تدفع للسك | إصدارات المجتمع المتميزة |
| **قائمة بيضاء مجانية + عام مدفوع** | القائمة البيضاء تسك مجانًا، والباقي يدفع | مكافآت المجتمع + البيع العام |

لأنواع القائمة البيضاء، تحتاج إلى تقديم قائمة بالعناوين (ملف أو مباشرة). يُنشئ الوكيل تلقائيًا شجرة Merkle ويرفعها إلى العقد.

### 4. بعد النشر

**سك وتوزيع الـ NFTs:**
> "Mint 50 NFTs from my collection and send them to the addresses in airdrop_list.txt"

تنسيق ملف العناوين — عنوان واحد في كل سطر:
```
0xAAA...BBB...CCC...
# الأسطر التي تبدأ بـ # تعليقات
```

أو مباشرة:
> "Mint 3 NFTs and send to: 0xAAA..., 0xBBB..., 0xCCC..."

**عرض الحاملين:**
> "Show me all holders of my NFT collection"

**التصدير إلى ملف:**
> "Export holder data to CSV"

**إعداد القائمة البيضاء:**
> "Set up a whitelist for my collection using these addresses: 0xAAA, 0xBBB"

**تحديث معلمات السك:**
> "Enable public minting at 0.05 PROS, max 5 per wallet"

## حل المشاكل

| المشكلة | الحل |
|-------|----------|
| عدم تطابق أبعاد PNG | تحقق أن جميع الملفات بنفس الحجم، أعِد التصدير إذا لزم الأمر |
| فشل رفع IPFS | تحقق من `PINATA_JWT` في `.env` وحصة حساب Pinata |
| **Pinata: حد 500 ملف** | الخطة المجانية = 500 ملف، 1 غيغابايت. الوضع أ: حوالي 250 NFT (2N ملف). الوضع ب: حتى 500-M من الـ NFTs. الوضع ج: حتى حوالي 500 NFT |
| Forge غير موجود | التثبيت: `curl -L https://foundry.paradigm.xyz \| bash && foundryup` |
| Pillow غير موجود | التثبيت: `pip install Pillow` |
| خطأ **Stack too deep** | أضف `via_ir = true` إلى `foundry.toml` — مطلوب لهذا العقد |
| خطأ تجميع Forge | تأكد من تثبيت OpenZeppelin v5: `forge install https://github.com/OpenZeppelin/openzeppelin-contracts@v5.0.2 --no-git` |
| فشل المعاملة على Pharos | استخدم دائمًا علامة `--legacy` مع `forge create` و `cast send` |
| غاز غير كافٍ | تحقق من رصيد محفظتك على Pharos |
| السك لا يعمل | تحقق أنك مالك العقد، وأن publicMintEnabled مفعّل للمجموعات العامة |
| `.env` لا يُحمَّل | يجب أن يبدأ كل أمر bash بـ `set -a && source .env && set +a` |
| صورة NFT لا تظهر في المستكشف | تأكد أن البيانات الوصفية تستخدم `ipfs://CID` (وليس عناوين البوابة). تحقق أن CID المجلد صحيح. |

## الأمان

- **لا تلصق أبدًا** المفاتيح الخاصة أو رموز JWT أو أي بيانات سرية في المحادثة
- جميع البيانات السرية مخزنة **فقط في ملف `.env`** — الوكيل يقرأه تلقائيًا
- يُضاف `.env` تلقائيًا إلى `.gitignore`
- يُضاف `state.json` أيضًا إلى `.gitignore`
- تأكد أنك تتحكم في مفتاح مالك العقد
- إذا ألصقت سرًا بالخطأ في المحادثة — بدّل ذلك المفتاح فورًا
